## 项目背景

`cps` 用于在前端工程中通过命令行完成图片压缩，减少手工处理图片资源的重复操作。

## 公开能力

- 通过 npm 安装并使用 `npx cps` 运行。
- 交互式选择目标文件夹。
- 支持选择压缩模式。
- README 说明支持 SVGA 压缩与已压缩文件识别。

## 公开边界

仓库公开了安装方式和操作流程，未披露压缩率、处理规模或生产环境收益。当前维护状态以 GitHub 仓库为准。
