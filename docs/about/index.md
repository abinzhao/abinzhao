# 关于赵建斌

## 我在做什么

- 把 Git、前端三剑客、工程化、后端和部署整理成连续教程。
- 构建可以真实使用的工具、组件和跨端应用。
- 用 WebGL、粒子与 AI 研究更有表现力的交互方式。
- 公开实现过程、方案取舍、失败原因和验证结果。

## 内容方法

一篇教程至少要回答四个问题：

1. 完成后可以做什么？
2. 具体应该怎样操作？
3. 为什么采用这种实现？
4. 如何确认结果真的正确？

项目和实验也遵循相同原则：视觉效果需要有实现说明，技术结论需要有验证依据。
