# 关于阿斌

我是阿斌，一名关注前端工程、HarmonyOS 与 AI 应用的开发者。`纯爱掌门人` 是对长期关系、真诚表达和认真创作的提醒，不是内容标签。

## 当前关注

- 让 AI 能力进入真实产品流程，而不是停留在一次对话。
- 建立能够长期维护的前端工程、工具和知识体系。
- 探索 HarmonyOS 的端侧能力和跨设备体验。
- 使用 Rust 与 Python 解决适合它们的问题。

## 工作原则

### 先建立证据

先复现、测量和核对真实上下文，再决定需要修改什么。

### 保持边界清晰

代码、文档和工具都应该明确输入、输出、错误状态和不处理的范围。

### 记录可以复用的判断

教程不只给出结论，还要说明为什么这样做、如何验证，以及方案在哪些条件下不再适用。
