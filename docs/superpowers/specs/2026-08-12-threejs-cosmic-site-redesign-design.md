# ZJB.DEV Three.js 数字宇宙全站重构设计

## 1. 目标

在现有 Astro 静态站点上重构统一的“数字宇宙”视觉系统，以真实地球纹理、Three.js 粒子银河、GLSL 星云与流光、电影式滚动镜头构成品牌体验。

核心体验：

- 首页从近地夜侧地平线出发，在约 `120–160vh` 的滚动距离内进入银河核心。
- 项目、博客、关于、实验室共享同一宇宙，但使用不同镜头、粒子密度和信息层。
- 深空主题与光昼主题同等设计，不把光昼主题处理为简单反色。
- DOM 承载内容、导航和可访问交互；WebGL 只负责装饰场景和空间反馈。
- 无 WebGL、无 JavaScript、低性能设备和 reduced-motion 下，内容与导航仍完整可用。

品牌保持：

- 品牌名：`ZJB.DEV`
- Slogan：把复杂，做得有意思。
- 站点语言：中文为主，英文仅用于品牌、技术名词和短标签。

## 2. 设计原则

### 2.1 真实与全息融合

真实感来自公开地球纹理、合理的夜侧光照、云层、大气散射、银河暗尘与多尺度恒星。全息感来自导航、状态标签、场景坐标和卡片流光，不用高密度 HUD 遮挡主体。

### 2.2 一个主场景

普通页面共用一个全局 WebGL 场景壳。页面通过配置切换镜头和图层，不为每个区块创建独立渲染器。Playground 实验详情不创建全局 WebGL，仅保留静态宇宙底图，由实验场景独占上下文。

### 2.3 内容优先

标题、正文、链接和卡片均为语义化 HTML。Canvas 标记为装饰内容并从辅助技术树隐藏。WebGL 初始化失败时不改变信息层级。

### 2.4 视觉强度分级

首页和 Playground 使用高强度场景；项目和关于使用中等强度；博客列表与正文使用低强度慢速背景。持续动画不与正文争夺注意力。

## 3. 已确认边界

| 项目 | 决策 |
|---|---|
| 框架 | Astro SSG + TypeScript strict |
| 3D | Three.js + ShaderMaterial |
| 滚动编排 | GSAP ScrollTrigger 或等价的单进度时间线 |
| 样式 | 现有 CSS 分层 + 语义令牌 |
| 场景范围 | 全站统一动态宇宙，页面变体 |
| 首页镜头 | 近地夜侧地平线 → 银河核心 |
| 滚动距离 | 一屏半电影推进，约 `120–160vh` |
| 主题 | 深空与光昼同等设计 |
| 纹理 | 本地化公开真实纹理，记录来源 |
| 声音 | 不加入音效或 BGM |
| 部署 | GitHub Pages，base 为 `/abinzhao` |

以下内容不进入本次范围：

- 修改现有内容集合字段、公开履历和项目事实。
- 引入 React 岛屿承担普通页面交互。
- 在运行时依赖外部纹理 CDN。
- 使用多个常驻 WebGL 上下文叠加视觉效果。
- 加入未经确认的访问量、客户、收益或性能指标。

## 4. 视觉系统

### 4.1 深空主题

| 语义 | 建议值 | 用途 |
|---|---|---|
| 宇宙底色 | `#010205` | 页面与场景底色 |
| 深蓝介质 | `#071522` | 星云、卡片内层 |
| 冷青信号 | `#80EEFF` | 状态、焦点、流光 |
| 暖白核心 | `#FFE0B8` | 银河核心、城市夜光 |
| 克制洋红 | `#C56FB3` | 次级流光、博客信号 |
| 主文字 | `#F3FAFC` | 标题与关键内容 |
| 次级文字 | `#9AAEB7` | 摘要与元信息 |

### 4.2 光昼主题

光昼主题表达高空日照、银白大气和浅蓝星图，不使用纯白背景叠加浅色发光。

| 语义 | 建议值 | 用途 |
|---|---|---|
| 高空底色 | `#EAF2F5` | 页面主背景 |
| 云层底色 | `#DCE8ED` | 次级区域 |
| 深蓝信号 | `#075B78` | 标签、链接、焦点 |
| 日照金色 | `#B66A24` | 核心与强调 |
| 深紫信号 | `#70517B` | 次级流光 |
| 主文字 | `#09171D` | 标题 |
| 次级文字 | `#425A64` | 正文 |

主题切换通过 CSS 变量和 Shader uniforms 同步完成，不销毁并重建场景。切换时仅使用 `200–300ms` 的颜色和曝光过渡。

### 4.3 字体与排版

- 标题使用现代中文无衬线字体栈，粗字重、紧字距和大尺度形成电影标题感。
- 正文使用高可读中文无衬线字体栈。
- 品牌、状态、坐标、技术标签和代码使用等宽字体。
- 首页标题在桌面端允许两行，每行保持完整语义；移动端不小于 `48px`。
- 正文行宽控制在 `65–75ch`，博客正文不叠加高亮粒子。

### 4.4 流光语言

流光分为三个层级：

| 层级 | 表现 | 约束 |
|---|---|---|
| 环境流光 | 星云介质、大气边缘、银河核心 | 慢速、低对比、不可抢正文 |
| 结构流光 | 卡片边缘、导航分隔、进度轨道 | 沿边界移动，不覆盖文字 |
| 交互流光 | Hover、Focus、指针附近反馈 | `200–300ms` 响应，键盘有等价状态 |

卡片使用伪元素和注册自定义属性实现边缘流光。内部水纹保持低透明度，不使用大面积玻璃拟态。

## 5. 场景架构

### 5.1 模块边界

```text
BaseLayout
└── CosmicSceneShell
    ├── SceneRuntime
    ├── QualityController
    ├── ThemeUniforms
    ├── ScrollTimeline
    └── SceneLayers
        ├── StreamerLayer
        ├── FarStarLayer
        ├── GalaxyLayer
        ├── NebulaLayer
        ├── PlanetLayer
        └── TransitStarLayer
```

职责：

| 模块 | 职责 |
|---|---|
| `CosmicSceneShell` | Canvas 挂载、页面变体选择、静态降级 |
| `SceneRuntime` | Renderer、Camera、帧循环、暂停与清理 |
| `QualityController` | DPR、粒子数、目标帧率和动态降级 |
| `ThemeUniforms` | 深空/光昼色彩、曝光和雾化参数 |
| `ScrollTimeline` | 将滚动位置归一化为 `0–1` 场景进度 |
| `SceneLayers` | 独立创建、更新、显示和销毁各视觉图层 |

### 5.2 页面配置契约

```ts
type CosmicVariant =
  | "home"
  | "projects"
  | "blog"
  | "article"
  | "about"
  | "playground"
  | "experiment"
  | "not-found";

interface CosmicSceneConfig {
  variant: CosmicVariant;
  intensity: "low" | "medium" | "high";
  camera: CameraKeyframes;
  layers: LayerVisibility;
  palette: ScenePalette;
  interaction: "none" | "parallax" | "scroll-cinematic" | "experiment";
}
```

页面只声明配置，不直接操作 Renderer 或共享图层。场景内部实现可替换，不影响页面组件。

### 5.3 渲染顺序

1. Streamer Shader 远景流光。
2. 远景恒星和全页闪烁星场。
3. 多层星云与暗尘介质。
4. 银河细粒恒星、核心星群和稀疏亮星。
5. 地球、云层、夜光和大气。
6. 滚动穿越粒子和局部全息扫描。
7. DOM 导航、标题、卡片和状态层。

透明图层统一管理 `depthWrite`、混合模式和顺序，避免核心过曝及暗尘硬切。

## 6. 首页镜头

### 6.1 首帧：近地轨道

- 地球半径放大并下沉，只显示下方夜侧弧面。
- 城市夜光只提取高亮区域，不整体染红地表。
- 云层独立缓慢旋转，大气边缘保持薄且克制。
- 银河位于天空中上部，呈斜向暗尘盘，不显示完整风车旋臂。
- 标题位于左侧暗区，视觉主体不穿过主要文字。

### 6.2 滚动推进

滚动进度使用平滑插值：

```ts
const eased = progress * progress * (3 - 2 * progress);
```

推进过程：

| 进度 | 场景 |
|---|---|
| `0–0.25` | 地球缓慢下沉，标题开始淡出 |
| `0.25–0.6` | 相机抬升并前推，银河和星云增强 |
| `0.6–0.85` | 近景粒子掠过，焦距收缩，银河核心接近 |
| `0.85–1` | 项目、博客、实验室节点卡片进入 |

相机推进、银河缩放和 FOV 变化由同一时间线驱动。不得叠加多个互相竞争的滚动监听器。

### 6.3 终帧：银河核心

- 核心位于画面中部偏左，右上文字使用柔和径向暗场保持可读。
- 星云由冷青、暖白和少量洋红组成，暗尘边缘保持自然噪声。
- 粒子分为细粒主体、核心星群、稀疏亮星和近景穿越星。
- 三个入口卡片位于底部，边缘流光与银河色彩关联。

## 7. 页面变体

### 7.1 项目

场景语义为“星图坐标”：

- 使用中等密度星场和多条细弱连接线。
- 精选项目对应较亮节点，普通项目保持 DOM 卡片，不把真实内容绘制进 Canvas。
- 筛选时只改变节点亮度和镜头轻微偏移，不重新生成整个粒子场。
- 项目详情降低粒子速度，保留单个目标坐标和远景星云。

### 7.2 博客

场景语义为“深空档案”：

- 博客列表使用低强度星云、慢速星尘和等宽坐标标签。
- 分类切换只产生短暂信号波纹，不触发大幅镜头移动。
- 文章详情保留低密度固定星场和极慢流光，正文区域使用高不透明阅读面板。
- TOC、代码块和链接不依赖 Canvas；阅读时不启用指针引力或穿越粒子。

### 7.3 关于

场景语义为“轨道身份舱”：

- 使用地球薄弧、大气晨昏线和低密度星场。
- 技术方向显示为真实文本分组，背景节点只做空间映射。
- 联系方式位于稳定的 DOM 区域，不使用需要追踪的悬浮按钮。
- 不展示未确认的经历年份、客户或指标。

### 7.4 Playground

场景语义为“高能实验舱”：

- 列表页使用高强度流光和动态粒子预览。
- 实验详情使用静态全局底图，不初始化全局 Renderer。
- 返回列表后，由列表页重新初始化全局场景。
- 每个实验提供暂停、重置和 reduced-motion 降级状态。

### 7.5 404

场景语义为“信号丢失”：

- 使用低粒子密度黑洞或引力透镜图形。
- 返回首页、项目、博客和实验室链接始终可见。
- WebGL 不可用时使用静态径向图形，不阻塞导航。

## 8. 交互与状态

### 8.1 指针

- 桌面端指针只产生 `2–4deg` 范围内的视差和局部流光增强。
- 不移动正文，不让交互目标逃离指针。
- 指针离开场景后平滑回中。

### 8.2 触摸

- 移动端不使用持续设备方向权限。
- 触摸只控制卡片状态和实验内部交互。
- 首页镜头仅由滚动驱动，避免滚动与拖拽冲突。

### 8.3 主题

- 首次访问跟随系统主题。
- 手动选择写入现有持久化机制。
- 主题切换同时更新 DOM 令牌、Renderer exposure 和 Shader uniforms。
- 存储不可用时继续使用当前系统主题。

## 9. 性能与降级

### 9.1 Three.js 运行时边界

浏览器场景继续按需动态加载，但不直接加载 `three` 的完整模块命名空间。项目提供单一受控运行时模块，只重新导出当前场景实际使用的类与常量，使 Vite 能移除未使用的 Three.js 导出。

约束如下：

- 首页宇宙场景、粒子银河和 Shader 艺术共用同一受控运行时。
- 不通过提高 `chunkSizeWarningLimit` 隐藏体积问题。
- 不改变粒子数量、地球几何精度、纹理质量或降级策略。
- Three.js 动态 chunk 的压缩前体积低于 Vite 默认 500KB 警告阈值。
- 新增 Three.js API 时必须显式加入受控运行时导出，避免恢复完整命名空间加载。

### 9.1 质量档位

| 档位 | DPR 上限 | 银河粒子 | 近景粒子 | 目标帧率 |
|---|---:|---:|---:|---:|
| 桌面高 | `1.6` | `100k–125k` | `6k–8k` | `60fps` |
| 桌面低/平板 | `1.35` | `55k–75k` | `3k–4k` | `45fps` |
| 移动端 | `1.2` | `35k–55k` | `1.5k–2.5k` | `30fps` |
| reduced-motion | `1` | 静态关键帧 | `0` | 无持续循环 |

粒子数量为上限，不是固定验收值。若连续采样帧率低于目标，先关闭近景粒子，再降低 DPR 和银河粒子密度。

### 9.2 生命周期

- 场景接近视口时初始化。
- Canvas 离开视口、文档隐藏或实验场景激活时暂停。
- 页面离开时取消动画帧、观察器、事件和 GPU 资源。
- 纹理、几何体和材质显式 `dispose()`。
- WebGL context 丢失时停止循环并显示静态降级图。

### 9.3 静态降级

静态关键帧保持与动态场景一致的构图：

- 首页：夜侧地球弧面与斜向银河。
- 项目：星图坐标和连接线。
- 博客：低密度星场与暗色阅读面板。
- 关于：大气晨昏线。
- Playground：实验首帧。

静态图使用本地资源或构建产物，不依赖运行时远程请求。

## 11. 可访问性

- Canvas 设置 `aria-hidden="true"`，不承载唯一信息。
- 导航、主题切换、筛选、卡片和实验控制可完整键盘操作。
- Focus 状态使用边框、位移和颜色组合，不只依赖发光。
- 深空与光昼主题的正文和控件满足 WCAG AA。
- reduced-motion 停止镜头推进、粒子穿越、闪烁和卡片位移。
- JavaScript 禁用时内容、链接、旧路由兼容页和主题基础样式可用。

## 12. 测试与验收

### 12.1 自动化

- 场景配置解析、质量档位和主题 uniforms 单元测试。
- 初始化、暂停、恢复、销毁和 context lost 测试。
- 首页滚动进度 `0`、`0.5`、`1` 的状态测试。
- reduced-motion 不启动持续动画循环。
- 博客正文不启用高强度交互和近景穿越粒子。
- GitHub Pages `/abinzhao` 下纹理、动态导入和链接路径正确。

### 12.2 浏览器验收

Playwright 覆盖 `1440px`、`900px`、`390px`：

- 无横向溢出。
- 首帧标题、地球和银河不互相遮挡。
- 终帧标题、卡片和银河核心可读。
- 移动端卡片、导航和按钮触控尺寸不小于 `44px`。
- 无 JavaScript 时内容和主要链接可用。

Chrome DevTools 检查：

- 控制台无应用错误。
- 网络无意外 `4xx/5xx`，生产环境不请求纹理 CDN。
- 页面隐藏和离开视口后帧循环暂停。
- 不出现阻断级长任务、明显 CLS 或持续内存增长。
- Lighthouse 性能、可访问性、最佳实践和 SEO 无阻断问题。

### 12.3 完成标准

- 首页实现已确认的近地轨道到银河核心镜头。
- 项目、博客、关于、Playground 和 404 使用统一宇宙页面变体。
- 深空和光昼主题均有独立可读的场景与 DOM 令牌。
- 桌面、移动端、reduced-motion、无 WebGL 和无 JavaScript 路径可用。
- 所有纹理本地化并记录来源。
- 相关单元测试、Astro check、构建、Playwright 和浏览器验收通过。

## 13. 实施边界

实施按以下依赖顺序展开：

1. 场景契约、质量控制和生命周期。
2. 本地纹理与共享星场、星云、银河图层。
3. 首页地球和滚动镜头。
4. 深空/光昼主题与卡片流光。
5. 项目、博客、关于、Playground 和 404 变体。
6. reduced-motion、静态降级和 context lost。
7. 响应式、性能、自动化和浏览器验收。

每个阶段保持站点可构建、主要路由可访问，并优先复用现有组件和测试边界。
