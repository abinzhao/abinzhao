# 紧凑型内页设计规范

## 目标

提高项目、文章、工具箱和关于页的首屏信息密度。除首页外，这四类一级页不再使用占据大面积首屏的说明 Hero；导航下方直接进入页面身份、筛选和核心内容。

本次同步覆盖中文和英文核心路由：

- `/projects/`、`/en/projects/`
- `/blog/`、`/en/blog/`
- `/toolbox/`、`/en/toolbox/`
- `/about/`、`/en/about/`

文章详情、项目详情的标题与元信息属于内容本身，不在本次移除范围。实验页不在本次范围。

## 设计方向

采用已确认的方案 A“平衡型紧凑归档”：

- 保留电影式深色视觉、圆角、阴影和流体背景。
- 导航与正文之间只保留紧凑页面标题栏。
- 标题栏包含短标签、页面名称和一行必要辅助信息。
- 桌面首屏必须看到筛选控件以及至少一组核心内容。
- 移动端标题栏改为单列，不使用固定高度，不产生横向滚动。

## 页面结构

### 项目

- 删除现有大型 `projects-hero`。
- 在内容容器顶部加入紧凑标题栏，显示“项目”、项目总数和一句短说明。
- 分类筛选紧接标题栏。
- 精选项目和更多项目保持分区，但缩小分区标题与垂直间距。
- 桌面端首屏至少露出两个项目卡片。

### 文章

- 删除现有大型 `blog-hero`。
- 紧凑标题栏右侧保留“归档 / 标签 / RSS”辅助导航。
- 标签筛选紧接标题栏。
- 文章列表提高行内信息密度，保持标题、摘要、日期和标签可扫读。
- 桌面端首屏至少完整显示第一篇文章。

### 工具箱

- 删除大型 `toolbox-hero`。
- 紧凑标题栏显示工具总数和“本地处理”状态。
- 搜索框与分类筛选位于同一工作区顶部。
- 工具卡桌面端改为三列，缩小卡片高度和无效留白。
- 分类标题改为紧凑分隔行，不再占据大块垂直空间。
- 搜索时隐藏空分类，避免出现无内容区域。

### 关于

- 删除当前超大姓名 Hero。
- 首屏改为“个人简介卡 + 当前状态列表”双栏结构。
- 技术坐标、工作原则和联系入口继续保留，缩小章节间距。
- 技术坐标桌面端使用三列，提高横向空间利用率。
- 联系入口使用紧凑网格，避免纵向单列占据过多高度。

## 视觉与响应式约束

- 页面主体宽度继续使用 `var(--content-wide)`。
- 标题栏顶部间距以导航实际高度为基准，桌面约 `5.5rem`，移动端约 `4.75rem`。
- 标题栏标题桌面不超过 `3rem`，移动端不超过 `2.25rem`。
- 卡片圆角继续使用现有 `--radius-card`，面板使用 `--radius-panel`。
- 所有按钮和交互控件保持至少 `44px` 触控尺寸。
- 不新增依赖，不改变内容数据结构和路由。

## 验收标准

- 四类中英文一级页均不再出现大型说明 Hero。
- 1440×900 下，导航后首屏可看到筛选和实际内容。
- 390px 下无横向溢出，标题、筛选和卡片不重叠。
- 工具搜索、项目筛选、文章筛选继续正常工作。
- 深浅主题、命令面板、语言切换和滚动导航不回归。
- 单元测试、Astro Check、Lint、构建和 Playwright E2E 全部通过。
