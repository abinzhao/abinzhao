# abinzhao 深色技术电影感个人站重构设计

## 目标

以已确认的第二版交互原型为视觉基线，把现有个人站重构为面向技术同行的个人品牌、工程作品与内容站。默认中文，核心页面支持英文和深浅主题；保留 Astro 静态生成、Content Collections、Pagefind、GitHub Pages 与实验页独立 Three.js 运行时。

品牌信息固定为：

- 品牌名：`abinzhao`
- 中文名：阿斌
- 昵称：纯爱掌门人
- 核心表达：在鸿蒙上，用前端的方式，把 AI 变成应用。

## 信息架构与独立路由

一级导航全部对应独立页面，不使用首页锚点模拟页面：

| 导航 | 中文路由 | 英文路由 | 职责 |
| --- | --- | --- | --- |
| 首页 | `/` | `/en/` | 品牌主张、当前信号、代表项目、公开轨迹和内容入口 |
| 项目 | `/projects/` | `/en/projects/` | 工程项目列表、筛选与项目详情 |
| 文章 | `/blog/` | `/en/blog/` | 技术文章、语言标签、标签和归档 |
| 实验 | `/playground/` | `/en/playground/` | 可运行实验列表与独立实验详情 |
| 工具箱 | `/toolbox/` | `/en/toolbox/` | 工具发现、搜索与分类 |
| 关于 | `/about/` | `/en/about/` | 工作原则、技术能力图谱与个人侧面 |

兼容路由继续保留；现有 `/search/` 作为命令面板的可访问、可索引降级入口，不再占桌面一级导航。

中文为默认语言。核心页面使用独立英文静态路由；文章保持原始语言，不强制逐篇翻译，并显示语言标签。语言切换跳转到当前页面的对应语言 URL；对应英文内容不存在时回退到英文首页。

## 首页叙事

首页顺序固定为：

1. Hero：品牌身份、核心主张、单一主行动“查看当前信号”。
2. 当前信号：3–5 个极简状态卡，仅公开方向、状态和可公开产物。
3. 代表项目：Singularity Engine、Repo Compass、Code Analysis。
4. GitHub 公开轨迹：Release、新项目与贡献活跃度的构建时静态快照。
5. 技术文章：一篇主文章加两至三篇次级文章。
6. 实验室：强调原理、性能边界和降级策略。
7. About 摘要与联系入口：GitHub、邮箱、掘金、CSDN。

“纯爱掌门人”作为认真且浪漫的人格签名出现，不作为夸张口号或情感内容定位。

## 视觉系统

### 基础气质

- 深色模式为技术电影感：近黑背景、冷白正文、青蓝信号色、紫色与薄荷色少量点缀。
- 浅色模式为同一技术语言的实验室日光版：冷白背景、深墨文字、降低透明度的彩色光层。
- 标题不使用负字距；正文强调长时间阅读清晰度。
- 内容层级主要依靠字号、留白、边界、背景明度和局部色彩，不依赖过多装饰。

### 圆角与阴影

- 小型按钮、输入框、标签：`12px`。
- 普通卡片、工具项、文章项：`18px`。
- Hero、主工作台、主要内容容器：`26px`。
- Header、分段控制和状态胶囊：`999px`。
- 阴影分为低、中、高三层：默认卡片只使用低层柔影；悬浮卡片使用中层柔影；命令面板与工具工作台使用高层深影。
- 边框使用低对比半透明颜色，避免硬直白线；卡片不嵌套装饰性卡片。

### 流体渐变

- 背景由 2–3 个低透明度、非规则椭圆光层组成，通过 `transform`、`border-radius` 与渐变位置缓慢变化，形成水流感。
- 周期控制在 18–30 秒，内容本身不随背景漂移。
- 鼠标光场与流体背景分离，避免每次指针移动触发布局或大面积重绘。
- 主站使用 CSS，不加载 Three.js、WebGL 或视频背景。
- `prefers-reduced-motion` 下关闭持续变形、文本流光和视差，只保留静态渐变。

## 全局导航

### 顶部状态

- 桌面端初始状态为页面上方宽幅胶囊，最大宽度与内容容器一致。
- 使用半透明背景、细边框和低层阴影；品牌、主导航、语言、主题、命令面板与 GitHub 入口在同一行。
- 当前页面使用有底色的胶囊状态，不使用下划线。

### 滚动状态

- 当滚动超过 `32px` 后进入紧凑状态。
- Header 最大宽度收窄，顶部间距减小，高度降低，背景不透明度和模糊度提高，阴影由低层过渡到中层。
- 品牌、导航项和操作区间距同步收紧，但不会隐藏关键入口。
- `width`、`max-width`、`padding`、`background-color`、`border-color`、`box-shadow` 和 `transform` 使用 `260–360ms` 缓动过渡。
- 状态仍由 `data-scrolled` 驱动；滚动监听被 `requestAnimationFrame` 合并，保持被动监听。
- 向上回到阈值内时完整反向过渡，不发生跳变。

### 移动端

- 顶部保持品牌、语言、主题和菜单按钮。
- 菜单使用独立浮层面板，圆角 `22px`，不是横向压缩桌面导航。
- 打开菜单时锁定页面滚动；`Escape`、选择链接和点击面板外部都能关闭。
- 触控目标不小于 `44px`。

## 鼠标与交互

- 桌面精细指针启用柔和光场跟随，使用 CSS 自定义属性更新位置。
- 自定义光标仅作为增强效果，链接、按钮和表单仍保留原生可用性与焦点状态。
- 项目、工具和实验卡片最多产生 `2–4deg` 轻微倾斜与 `2–4px` 位移；退出后平滑复位。
- 主要按钮采用轻量磁吸，不改变文档流。
- 触屏、低性能设备和 `prefers-reduced-motion` 下关闭光标、倾斜、磁吸与视差。
- 所有交互均支持键盘操作，不以 hover 作为唯一信息载体。

## 页面设计

### 项目

- 列表优先展示问题、角色、技术证据、当前状态和仓库入口。
- 项目详情按“问题 → 约束 → 方案 → 关键判断 → 结果 → 边界”组织。
- 首页与列表页不使用虚构指标；无法确认的数据不展示。

### 文章

- 列表采用一篇主文章和可扫描的次级列表。
- 详情页保持阅读进度、目录高亮、上一篇/下一篇、相关内容和 RSS。
- 阅读正文使用稳定实色，不使用渐变文字或低对比玻璃层。

### 实验

- 列表展示运行状态、技术栈、性能边界和降级方案。
- Three.js 只在具体实验详情加载；主站和实验列表不加载。
- 实验详情外围 UI 使用同一圆角和主题系统。

### About

- 重点为工作原则、技术能力图谱和个人侧面。
- 不展示真人照片、传统履历时间线或技能熟练度进度条。
- 技术能力图谱采用语义分组，不用百分比表达熟练程度。

## 工具箱

### 组织方式

- `/toolbox/` 为统一索引、搜索和分类页面。
- 每个工具拥有独立 URL，例如 `/toolbox/json/`，便于分享、搜索和直接访问。
- 工具实现按页面按需加载；首页只加载卡片元数据，不加载全部处理逻辑。
- 输入默认不上传、不持久化；需要保存时必须由用户显式操作。

### 首发工具

开发者常用：

- JSON 格式化、压缩和校验
- Base64 编解码
- URL 编解码
- Unix 时间戳转换
- UUID 生成

文本处理：

- 字数与行数统计
- 行去重
- 大小写和命名格式转换
- Markdown 预览

前端设计：

- HEX、RGB、HSL、OKLCH 颜色转换
- CSS 渐变生成器
- CSS 阴影生成器
- CSS 单位换算

AI 提效：

- Prompt 结构器
- Token 粗略估算
- 结构化提示词模板

所有工具先实现确定性、本地处理功能，不接入远程 AI API。

## 命令面板与搜索

- `Command/Ctrl + K` 打开命令面板。
- 可搜索页面、项目、文章、实验和工具，也可执行语言、主题切换。
- 保留可见按钮，不能只依赖快捷键。
- Pagefind 继续负责静态内容搜索；操作命令使用本地注册表。
- 无结果、索引未加载和脚本失败时提供明确状态与普通搜索页入口。

## GitHub 数据

- 构建时同步 Release、新项目和贡献活跃度，不在客户端直接调用 GitHub API。
- 生成静态快照并记录更新时间。
- API、网络或限流失败时使用仓库内上次成功快照；无快照时隐藏该模块并保留稳定布局。
- 不展示完整 commit 流，不制造活动噪音。

## 工程边界

- 沿用 Astro 7、TypeScript strict、Content Collections、MDX、Pagefind 和 View Transitions。
- 不新增前端框架或全局状态库。
- 主站不加载 Three.js、GSAP 或远程背景媒体。
- 不改变公开内容事实，不手工编造 GitHub 指标。
- 保留 `/abinzhao/` base path、SEO、RSS、旧兼容路由与静态部署能力。
- 主题、语言和动效偏好在首屏绘制前初始化，避免闪烁。

## 错误与降级

- JavaScript 失败时独立页面导航、内容阅读、工具说明和普通搜索入口仍可用。
- 工具输入无效时在工作区内显示可定位错误，不弹出阻塞式提示。
- 剪贴板、分享和存储权限不可用时提供可选择文本与明确提示。
- GitHub 数据同步失败使用静态快照。
- 不支持 `backdrop-filter` 时使用不透明表面色。

## 验证与验收

- 390px、768px、1024px、1440px 无横向溢出和文字遮挡。
- 一级导航均访问独立页面；当前页面状态和语言对应 URL 正确。
- 导航在 `0px`、`32px` 阈值两侧平滑过渡，无布局跳变。
- 深浅主题的正文、链接、按钮、禁用态和表单达到 WCAG AA。
- 鼠标增强交互不影响键盘、触屏和 reduced-motion。
- 所有首发工具包含正常、空输入、无效输入和大输入测试。
- GitHub 同步包含成功、失败回退和无快照场景测试。
- 主站网络请求不包含 Three.js、GSAP 或远程视觉素材。
- 执行单元测试、ESLint、Astro 类型检查、生产构建、Playwright E2E、Lighthouse 和 `git diff --check`。
