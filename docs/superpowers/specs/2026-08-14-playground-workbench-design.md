# 实验页面工作台重构设计规范

## 目标

将实验索引页与三个实验详情页统一为“画布优先实验工作台”，突出实验可运行、可交互的产品属性，同时保留原理说明、性能边界、无 JavaScript 降级和移动端可用性。

本次覆盖：

- `/playground/`
- `/en/playground/`
- `/playground/particle-galaxy/`
- `/playground/shader-art/`
- `/playground/physics-sandbox/`

不改变实验内容集合、URL、场景注册表、Canvas 渲染逻辑、运行时状态机或交互参数。

## 设计方向

采用已确认的方案 A“画布优先实验工作台”：

- 延续站点现有流体背景、电影式明暗层次、圆角和阴影。
- 索引页用一个主实验带动两个次实验，形成明确浏览顺序。
- 详情页让运行画布成为第一视觉焦点，说明内容成为紧凑辅助侧栏。
- 状态、操作和动态参数属于同一运行时框架，不再与画布割裂。
- 页面表达更接近可操作实验产品，不做后台仪表盘或纯作品画廊。

## 索引页

### 页面身份

- 移除占据大面积首屏的 `playground-hero`。
- 使用与其他一级页一致的紧凑标题栏，包含短标签、页面名称、实验总数和一句说明。
- 中文标题为“实验室”，英文标题为“Lab”。
- 桌面端导航后首屏必须看到主实验视觉和至少一个次实验入口。

### 实验编排

- 保持现有排序规则：精选优先，其次按日期和标题排序。
- 第一个实验为主实验，占据索引内容区约三分之二宽度。
- 主实验卡使用大幅视觉预览，正文显示编号、标题、描述、技术标签和进入操作。
- 后两个实验垂直排列在右侧，各自使用紧凑预览、标题、简述和技术标签。
- 中英文索引复用同一 `ExperimentCard` 结构和网格规则，英文页面只替换界面文案。

### 移动端

- 390px 下改为单列，主实验与次实验按排序顺序排列。
- 主实验不使用固定大高度，视觉区域保持稳定宽高比。
- 所有卡片链接具备至少 44px 可操作区域，不产生横向滚动。

## 详情页

### 紧凑身份区

- 返回入口、实验编号、标题、描述、技术标签和源码入口组成紧凑页头。
- 页头不再使用超大展示标题，不抢占运行画布的首屏空间。
- 桌面 1440×900 下必须看到完整页头、运行状态、核心控制和画布主体。

### 运行工作台

- `ExperimentShell` 位于详情主列，占可用宽度约 72%。
- 说明侧栏占约 28%，包含实验目标、交互方式和性能与降级。
- 运行状态放在画布上方的紧凑状态条。
- 暂停、继续、重置、重试和动态参数放在同一个控制条中。
- 画布维持稳定宽高比和最小高度，状态文本、按钮显隐或动态控件不得改变整体布局宽度。
- 运行区桌面端保持粘性；说明侧栏正常滚动，避免滚动时失去实验上下文。

### 运行状态

- 保留 `idle`、`loading`、`ready`、`paused`、`error` 状态和现有状态文案。
- 保留 Canvas 的 `aria-hidden="true"`，可访问状态由文本区域提供。
- WebGL 不可用、运行时失败或减少动态效果时继续展示静态视觉降级。
- 无 JavaScript 时保留标题、说明、返回入口和 `noscript` 提示。

### 移动端

- 900px 以下改为单列，顺序为页头、运行工作台、说明内容。
- 运行区取消 sticky，避免移动端滚动和视口高度冲突。
- 控制条允许换行，按钮触控尺寸不低于 44px。
- 画布高度受视口约束，不超过 `70vh`，不产生横向溢出。

## 样式边界

- 页面宽度使用 `var(--content-wide)`。
- 页面卡片使用 `--radius-card`，运行工作台使用 `--radius-panel`。
- 不新增依赖，不新增位图素材；三个实验继续使用现有运行画布和 CSS 静态预览。
- 不修改实验内容 frontmatter、场景实现和运行时公共 API。
- 删除或收敛仅服务旧实验布局的重复样式，实验页视觉规则集中在 `playground.css`。

## 验收标准

- 中英文实验索引使用相同结构，均显示三个真实公开实验。
- 1440×900 下索引首屏看到主实验与次实验入口，详情首屏看到画布主体。
- 三个详情页 Canvas、运行状态、控制按钮和动态参数继续正常工作。
- 390×844 下索引与详情无横向溢出、遮挡或控制重叠。
- 无 JavaScript 时实验说明、返回入口和降级提示可用。
- 深浅主题、语言切换、命令面板、滚动导航不回归。
- 单元测试、Astro Check、Lint、构建和 Playwright E2E 全部通过。
