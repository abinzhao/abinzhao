## 分类原则

- **WebGL**：场景、材质、Shader、后处理和图形性能。
- **AI**：模型交互、RAG、Agent、多模态和本地模型。
- **粒子**：流场、GPU 粒子、文字粒子和音频响应。
- **创意交互**：指针、触控、滚动和图像形变。
- **功能实验**：浏览器 API、文件处理、实时协作与可视化。
