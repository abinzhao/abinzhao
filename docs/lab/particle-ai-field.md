# AI 粒子光场

<p class="content-lead">
粒子从随机位置聚合为 AI 字形，同时根据指针位置产生轻微偏移。这个实验重点验证粒子数量、设备性能和交互反馈之间的平衡。
</p>

<ParticleFieldDemo />

## 实现目标

- 粒子从随机状态平滑收敛到目标位置。
- 桌面端响应鼠标，触控端保持稳定构图。
- 页面失焦或画布离开视口后停止渲染。
- 减少动态模式下停止连续动画。
- WebGL 不可用时保留静态光场。

## 核心思路

每个粒子同时保存当前位置与目标位置。每一帧只向目标移动一小段距离：

```ts
position.x += (target.x - position.x) * 0.035;
position.y += (target.y - position.y) * 0.035;
```

指针不会直接拖动粒子，只改变目标位置附近的小幅偏移，因此正文和界面不会跟随鼠标漂移。

## 性能分级

| 场景 | 粒子数量 | 交互 |
| --- | ---: | --- |
| 桌面高性能 | 900—1400 | 指针响应、连续动画 |
| 触控设备 | 约 620 | 预设运动 |
| 减少动态 | 约 360 | 静态呈现 |
| WebGL 不可用 | 0 | CSS 静态光场 |

## 效果验证

1. 调整粒子密度，画布重新建立场景。
2. 调整响应强度，指针附近的偏移幅度发生变化。
3. 暂停实验后，Canvas 被静态遮罩覆盖。
4. 切换深浅主题，粒子与连接线颜色随主题变化。
