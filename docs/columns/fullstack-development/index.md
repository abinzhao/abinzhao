# 全栈开发：前端基础与静态站点实战

这套专题面向零基础读者，目标不是记住标签和属性，而是建立一条可以反复实践的完整路径：

1. 用 HTML5 写出语义正确、可访问的页面结构。
2. 用 CSS3 完成布局、响应式设计、视觉样式和动画。
3. 用 Chrome DevTools 定位样式、网络、脚本与性能问题。
4. 将知识应用到一个原生 HTML、CSS、JavaScript 静态博客。
5. 完成部署、性能检查、无障碍检查和上线验收。

## 阅读方式

首次学习建议按章节顺序阅读，并把每一段完整代码放进本地项目运行。已经具备基础时，可以按以下路径选择：

- **页面结构**：第 0–1 章。
- **CSS 布局与视觉**：第 2–5 章。
- **CSS 动画与性能**：第 6–10 章。
- **浏览器调试与渲染原理**：第 11–12 章。
- **静态博客实战**：第 13–19 章。

## 开始前准备

只需要安装一个现代浏览器和一个代码编辑器。教程主体不依赖框架或构建工具；本地预览时使用任意静态文件服务器即可。每章均按“知识点 → 完整代码 → 调试方法 → 常见问题”组织，完成实战后会得到一个可部署的个人博客。
