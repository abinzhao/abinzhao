# 构建可维护的 ArkTS 页面架构

一个页面的复杂度，往往不是来自单个组件，而是来自状态、交互和依赖在同一处堆积。

## 先定义边界

将页面状态、可复用视图和领域操作分别放在清晰的边界内。页面只负责编排，组件只负责呈现，操作函数只负责改变状态。

## 让约束可见

当命名、目录和状态流转拥有统一约定时，下一次修改不需要重新理解全部上下文。
