# 面向个人开发者的静态站点

内容型个人站点不需要先引入服务端。先把内容、结构和发布流程做成可验证的静态产物。

## 内容是源代码

Markdown 文章与 YAML 配置进入版本控制，文章、专栏与导航由构建时索引自动生成。

## 部署保持简单

构建产物只是一组静态文件，GitHub Pages 可以承接发布，不需要维护额外的运行时服务。
