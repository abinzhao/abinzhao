# 专题

专题回答“如何完成一个完整目标”。它会串联多个基础教程，并把架构、实现、验证和边界放在同一条路径中。

## 实践路径

### [从零建立现代前端工程](./frontend-project.html)

产物：一个具备类型检查、自动化测试和静态发布能力的应用。沿工具链、组件、质量与交付四个阶段推进。

### [完成一个 Node.js 全栈应用](./fullstack-project.html)

产物：浏览器前端与 HTTP API 连接的任务服务。覆盖请求契约、数据库事务、鉴权、错误处理和生产运行。

### [浏览器插件从开发到发布](./browser-project.html)

产物：一个可加载、可调试、权限明确的 Manifest V3 扩展。依次完成内容脚本、消息通信和发布检查。

### [本地优先的 AI Agent 应用](./local-agent.html)

产物：一个具有工具权限边界、可重放执行记录和评测用例的 Agent 原型。远程模型请求的数据出口需要单独说明。

每条路径都有对应的教程正文和阶段验收条件。先完成每一阶段的可观察结果，再进入下一阶段。
