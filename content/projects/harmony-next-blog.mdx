## 项目背景

这是一个公开的 HarmonyOS Next 开发知识库，内容覆盖 ArkTS 语言基础、ArkUI 组件与布局、响应式设计、跨端实践、性能优化和构建发布。

## 公开能力

- 使用 VitePress 组织 Markdown 技术内容。
- 按 ArkTS、ArkUI、跨端、性能和构建等方向划分知识结构。
- 通过代码示例解释基础语法、布局方式和工程实践。

## 公开边界

仓库公开了教程内容和知识组织方式，未披露团队协作过程、使用规模或量化效果。当前维护状态以 GitHub 仓库为准。
