## 项目背景

`scioPro` 是一个面向 React 开发的多包工具仓库，公开内容包括组件库、Hooks 库和工具函数库。

## 公开能力

- 使用 Monorepo 管理多个可独立使用的包。
- React 组件、Hooks 与工具函数按职责拆分。
- TypeScript 代码和类型定义。
- ES Modules 与按需使用方式。
- 提供独立文档站点。

## 公开边界

仓库 README 描述了包结构、安装方式和浏览器兼容范围，未披露使用方数量或生产收益。当前维护状态以 GitHub 仓库为准。
