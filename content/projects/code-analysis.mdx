## 项目背景

该工具用于分析前端代码调用关系，并面向大型 Web 应用的依赖治理场景输出分析结果。

## 公开能力

- 提供 CLI 和 API 两种使用模式。
- 支持代码调用分析报告。
- 支持代码评分和阈值告警。
- 支持黑名单 API 标记。
- 支持依赖 API 趋势分析和自定义分析插件。

## 公开边界

仓库公开了安装方式、配置字段和使用模式，未披露实际接入项目、治理规模或量化结果。当前维护状态以 GitHub 仓库为准。
