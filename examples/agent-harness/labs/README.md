# Harness 扩展机制实验

从示例项目根目录运行 `npm run labs`，或用 `node --test test/labs.test.mjs` 验证拒绝与恢复路径。实验只依赖 Node.js 22，不安装包、不请求模型、不执行 Shell 命令、不发网络请求。运行器使用系统临时目录，结束后清理自己创建的夹具。

| 实验 | 实际实现 | 阅读章节 |
| --- | --- | --- |
| `skills.mjs` | 从本地文件读取目录元信息，按来源消歧；调用时检查内容摘要并加载正文 | 19–21 |
| `policies.mjs` | 一次性、带期限的审批凭据，绑定工具、argv、cwd 和声明副作用；硬拒绝优先 | 52–54 |
| `context.mjs` | 给来源分标签，按完整组选择上下文，保留必需事实与输出预算 | 31–34 |
| `workflow.mjs` | 校验 DAG、步骤预算、检查点版本与任务修订；恢复已完成结果，阻止重放不确定副作用 | 57–59 |
| `eval.mjs` | 统计人工标注的结果，保留缺失样本，对同一任务集做配对比较 | 68–69 |

`run.mjs` 串联五个独立实验。其 JSON 是机制执行结果；其中评测记录是明确写在代码中的人工夹具，不是模型质量、真实任务效果或成本测量。

## 动手修改

1. 给技能根目录增加第二个 `inspect`，用未限定名称加载，观察歧义拒绝。改用 `project/inspect` 后再加载。发现后修改文件，观察摘要失配。
2. 审批 `git status` 后尝试消费为 `git push`，观察绑定拒绝。原始 argv 仍可以消费一次；再次消费、超时消费和网络硬拒绝分别验收。
3. 改变上下文预算，观察 `call` 和 `result` 同时保留或同时丢弃。把必需组成本提高到剩余预算以上，应明确报错。
4. 运行工作流一个步骤，把 JSON 检查点读回再恢复，确认第一步不再执行。把任务 revision 改成 `"2"`，旧检查点应拒绝。给不安全任务制造“动作发生后连接丢失”，恢复应阻塞而非重复动作。
5. 删除一个评测结果，把它改成 `passed: null`，观察缺失项仍留在总样本分母。配对比较缺少任务或重复任务应拒绝。

## 边界

技能文件的教学解析器只支持单行 `name`、`description`，不是完整 YAML、完整 Agent Skills 规范校验器，也不加载脚本和引用文件。发现阶段读文件提取元信息，但不把正文放入模型上下文；这一区分涉及上下文成本，并不意味着磁盘正文完全没有读取。

路径检查、摘要比较和审批票据演示执行契约，不构成操作系统沙箱。目录可能在检查后被本机其他进程替换，Node 路径检查不能消除 TOCTOU。审批的副作用字段必须由可信工具适配器计算，模型自报 `effects: ["read"]` 没有授权效力。本实验不实际执行审批动作，不持久化审批票据。

上下文计量由调用方传入，示例使用“每块成本 1”便于观察选择结果；它不是 Token 计数器。`group` 是可信装配器划定的完整协议组；调用方若把工具调用与结果错误分组，此函数不会自行修复协议。

检查点写入采用临时文件再 rename，单进程实验可以从磁盘恢复；没有 `fsync`、跨进程锁、结果完整性签名或任务代码哈希。revision 必须随实现语义变化更新。完成结果只能是 JSON 可序列化值。外部动作与本地提交之间仍有崩溃窗口：不安全动作的 running/failed 快照需要人工或服务端幂等查询协调，不能声称 exactly-once。

这些实验没有接入 `src/agent.mjs` 的基础循环。独立运行与测试使每个机制可以观察、解释和替换；进入生产前还需实现相应章节的协议适配、强隔离、耐久存储和真实任务验收。
