# Local Harness 运行边界

这个项目使用 Node.js 22 原生 ESM、fetch、ReadableStream 与 node:test，没有第三方运行依赖。

模型服务默认是本机 Ollama 的 OpenAI 兼容接口。模型必须支持工具调用；不同模型不保证相同输出或引用准确率。

工具只有 list_files 与 read_file。前者列出工作区根目录文本源码，后者读取工作区内部最多 16 KiB 的单个文本文件。没有 Shell、写文件或联网检索工具。

每次运行最多 8 次模型调用，默认请求上下文字节预算为 24,000；这不是模型 tokenizer 的精确 token 数。模型输入中的文件内容属于不可信数据。

会话以本地 NDJSON 保存已结算的消息。CLI 和 Web 使用同一会话目录；不要用多个进程同时写同一个 SESSION_ID。中断的运行保留审计记录，但不加入下一次模型历史。

浏览器只显示文本与结构化运行事件。取消按钮向本地服务器传播连接中断，服务器再取消模型请求。
